
# Budget Tracker

## Project Description

Budget Tracker is a simple web application designed to help users manage and monitor their daily expenses.

This project was improved using CSS to create a clean, modern, and professional user interface.

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Design Improvements

### 1. Color Palette
I used Navy Blue, Green, White, and Light Gray to create a consistent and professional design.

### 2. Typography
I used:
- Poppins for headings.
- DM Sans for body text and form elements.

### 3. Form Styling
The Add Expense form includes:
- Proper padding and spacing.
- Rounded input fields.
- Consistent button styling.
- Focus effects on input fields.

### 4. Expense Table
The expense table includes:
- A dark blue header.
- Proper cell spacing.
- Borders.
- Alternating row colors.
- Hover effects.

### 5. CSS Box Model
I applied:
- Margin to separate sections.
- Padding to create internal spacing.
- Borders to define sections.
- Border-radius for rounded corners.
- Box shadows to create depth.

## Project Files

- index.html: Contains the structure of the Budget Tracker.
- style.css: Controls the visual design and styling.
- README.md: Explains the project and its design improvements.

## Conclusion

This project demonstrates how CSS can transform a basic HTML application into a more attractive, organized, and user-friendly Budget Tracker.
